# Third-party notices

The package contains only cropped, drawing-ready map coordinates and elevation values rather than the original geographic source files.

- Elevation background: GMTED2010-derived DEM used solely for the Figure 4 map display. Cite the GMTED2010 data product when reusing the elevation layer.
- Administrative and coastline linework: extracted coordinate geometry used solely to redraw the submitted China-domain figure panels. Users are responsible for confirming the terms of the original boundary source before redistributing modified geometry independently.
- Times New Roman is not bundled. The renderers fall back to Times or DejaVu Serif when it is unavailable.
